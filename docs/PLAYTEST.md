# 试玩记录

> **所有者：开发 Claude。** 策划 Claude 只读。记录开发者试玩后的原话，越原始越好；
> 括号里是开发 Claude 的补充说明，不是开发者说的。最新的在最下面。

1. （右摇杆瞄准阶段）开发者要求把右摇杆还给镜头，攻击改跟移动方向
2. "永远朝镜头前方"：比其他方案顺手
3. 从正后方看不到攻击——"你这个在角色的正后方，就有点那个什么了，看不到攻击啊"
   （几何上：屏幕上能看到的长度 ≈ 实际长度 × sin(视线与伪足夹角)，俯视 15° 时约 26%。
   开发者随后把俯视角调到了 35°，并加了肩后偏移选项）
4. "目前位置还是很混乱" → 改为经典类魂操作后："确实操作顺畅了"
5. 类魂操作："上下两个维度没办法灵活调整攻击向，这样就相当于传统平地类魂了"
6. 加了三个上下开关后："感觉差不多吧，也好不到哪去。关键是这种瞄准射击的确实太难了"
7. "后面我们可能主要的攻击方式也不需要这么细致的自由度，后面再说吧，这阶段先保持这种"
8. 开发者在考虑要不要干脆退回传统平面类魂：第三人称下多出来的几个自由度很难精确操作，第一人称反而没这个问题
   （策划 Claude 的意见：先排除"攻击看不见、场上没威胁"两个干扰再评估）
9. 加了屏幕中心索敌后："有点对味了"，随后要求加准星
10. 试玩挥扫 + 屏幕中心索敌 + 准星："感觉还可以，如果后续有更优化的决定再说吧，
    因为肯定动作系统是一个综合的手感感觉"
11. （2026-11-25，敌人第 2 步完成后）待试玩
