## 能玩到什么

- 半径 20 的半透明球形竞技场，下方 22 米处有一块参照地面，有雾
- 8 个不动的靶子：默认撤掉，`Arena.show_dummies` 打开才出现
- **3 只会攻击的敌人**：上方、下方、侧面各一只，见下方《敌人》
- 玩家血量 100，屏幕底部血条；受击闪红、镜头抖、击退、短暂失控；归零直接回满
- 主角：球形细胞，前面有个深色小方块标出正面
- 屏幕中心准星：平时白色，有目标被选中时变黄（和目标头顶标记同色）
- 左上角调试面板：开关状态、攻击俯仰、伪足状态、蓄力、长度、速度、命中数、被击倒次数、全部敌人状态、手柄原始输入

## 操作（类魂方案，唯一保留的方案）

| | 手柄 | 键鼠（临时，未定） |
|---|---|---|
| 移动（相对镜头） | 左摇杆，身体转向移动方向 | WASD |
| 闪避 | B | 鼠标右键 |
| 上升/下降 | **LB / LT**（2026-11-25 前是 RB / LB） | 空格 / Shift |
| 攻击 | RT：轻点出短伪足，按住蓄力出长伪足 | 鼠标左键 |
| 镜头 | 右摇杆，松手 1 秒后恢复自动回正 | **没有**，只有自动跟随 |

- 推着方向按攻击会先瞬间转过去；蓄力时还能慢慢修正方向；伪足伸出后朝向锁死
- **攻击方向的优先级**：
  1. **方向攻击**：按住升/降键出招 = 上挑/下砸（70°）；出招期间升降键不再推动身体
  2. **准星索敌**：伪足够得着的敌人里，选投影离准星最近的（准星在屏幕中心偏上 12%，限屏幕高度 30% 半径内），
     攻击直接打向它，身体也转过去；目标头顶显示黄点。镜头对准谁就打谁
  3. **身体正面**：没有目标时朝身体正面打，上下角度叠加镜头俯仰偏移（右摇杆往上看就往上打）
- **攻击朝的是身体正面或索敌目标，不是镜头前方**。身体转向移动方向，镜头由右摇杆独立控制，两者经常不一致
- 索敌范围随蓄力增长：待机时只够得着 1.5 米内，蓄满后 7 米
- 镜头：默认俯视 35°，永不翻滚，有可调的肩后偏移（默认 0）

## 伪足攻击

- 形态：挥扫（直刺已删除）
- 状态机：待机 → 蓄力 → 伸出 →（挥扫）→ 停留 → 收回
- 轻点 1.5 米，蓄满 7 米（0.6 秒蓄满）
- 长伪足伸得慢、停得久、收得慢，伸出期间移动速度降到 20%
- **挥扫**：
  - 伪足先朝弧的一端伸出（不判定），伸到位后扫过整个弧，然后停留、收回
  - 轻点 70° / 0.08 秒，蓄满 150° / 0.25 秒
  - 挥扫平面倾角可调：0° 水平左右扫，90° 竖直下劈，45° 斜劈
  - 连续出招左右交替；一次挥扫能打中路径上所有目标，每个只算一次（可切成"碰到第一个就停"）
  - 判定是覆盖整条伪足的胶囊体，按角度步长逐段检测
  - 蓄力预告：半透明扇形覆盖将要扫过的范围；膜在起点那一侧鼓起
- 命中：目标闪色；全局时间定格 0.05 秒（轻）到 0.14 秒（重）
- 收回途中提前按下的攻击会被缓冲，收完立刻接下一次

## 敌人（只有一种，`scenes/enemy.tscn`）

- 白盒杆状胶囊，长轴指向玩家或冲刺方向；头顶文字显示状态和血量（穿墙可见）
- 状态：**接近**（游走）→ **前摇** 0.8 秒（膨胀到 1.35 倍、由绿变橙）→ **攻击**（16 米/秒冲刺 7 米）→ **硬直** 0.9 秒（变暗）→ 接近
- 冲刺方向在前摇进行到 75% 时锁定，之后玩家移动就能躲开
- 每只敌人记住自己相对玩家的方位，只绕竖直轴游走：上方的一直在上方，下方的一直在下方
- 保持 5 米距离；出手间隔 1.5–3.5 秒随机。**没有限制同时攻击的人数**
- 命中玩家：15 伤害 + 9 米/秒击退；玩家受击后 0.5 秒无敌、0.2 秒失控
- 被玩家打：轻 8 / 重 25 伤害，40 血；前摇中被打会被打断，冲刺中不会
- 死亡后 3 秒在出生点复活
- 所有数值都在检查器里
