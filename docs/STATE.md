## 上一批改动（2026-11-28 第九批：冲击系统、命中粒子重做、受击愣住）

按策划 2026-11-28《把冲击做成系统、粒子改方向+指数减速、受击要打断朝向》做的。

- **冲击系统**（`scripts/fx/impact_config.gd` + `scripts/fx/hit_tier.gd`）：每档 HitTier 只填一个主强度 `impact`（轻 1 / 重 2.5 / 弹反 3.5 / 受击 2 / Boss 5），
  定格、镜头抖、后坐、击退、敌人形变、命中粒子（数量/初速/大小/存活）全部 = 基准 × impact^指数 × 该档单项倍率（默认 1）。
  基准和指数在 ImpactConfig（Player 的 `impact_config`，为空用全局默认）。指数按换系统前的轻/重两档实际值反推，所以定格、镜头抖手感不变；
  **后坐、击退的基准整体上调 1.5 倍**（轻击后坐 2→3、重击 5→7.5；轻击击退 3→4.5、重击 10→14.8）。
  Player 的 recoil_light/heavy、Enemy 的 knockback_light/heavy 已删；受击档用 `shake_mult = 3.45` 保住原来的 0.7 抖动
- **命中粒子重做**（`scripts/fx/hit_fx.gd`）：环删了。胞质沿冲击方向（刃的运动方向）从目标另一侧迸出，指数减速（体液黏滞）后停住、慢慢漂、淡出。
  大小 ±20%、速度 ±30%、朝向随机。自己推进，命中定格时停住
- **受击愣住**：敌人挨打后 0.6 秒保持挨打那一刻的朝向（`hit_facing_hold_time`），之后慢慢转回来（不一帧扭回）。没动 AI
- 测试：`hit_wobble_smoke` 扩到 16 项（冲击系统 4 项、愣住 2 项）；`hit_wobble_strip` 加了命中粒子

## 上一批改动（2026-11-28 第八批：刃有白边、前缘硬后缘软、刀变细、一刀之内加缓冲）

按策划 2026-11-28《软硬分在宽度上、刀变细 + 挥击平面倾斜、刃要用膜的材质》做的。

- **刃的白边**：刃一直用的是膜的同一个材质，没断。真正原因：刃截面极扁，法线几乎全朝上下，菲涅尔边缘光只落在刃口不到一像素宽的一圈，
  所以看不见。现在按截面位置给刃的两条长边补上同色的白边（`blade_edge_rim`）
- **软硬分在宽度上**：前缘（挥过去那一侧）硬、不透明、不起伏、形状每次一样；后缘半透明、跟着膜流动、往外飘出不规则的一圈，
  每次出手换随机种子（`blade_back_hardness` / `blade_back_ragged`）。判定只用中线，和后缘的随机无关
- **刀变细**：0.7 → 0.45 米。**刀面朝镜头翻**最多 35°（`blade_face_roll_max_deg`）。⚠ 策划定的是"倾斜挥击平面"，
  我做的是只翻刀面——翻挥击平面会让挥击轨迹变斜、改变能打到谁，那是手感；只翻刀面能达到同样的"细了还是个面"，轨迹和判定不动。已告知策划
- **一刀之内加缓冲**：挥扫进度 = 进度² 和平滑曲线按 0.3 混合（`swing_end_soften`），到头不再满速硬停。两刀之间的边界没动
- 剪影：`docs/img/silhouette_2026-11-28_softback.png`；俯视特写（前缘白亮、后缘软）：`docs/img/blade_softback_closeup_2026-11-28.png`

## 上一批改动（2026-11-28 第七批：判定跟着画面弯、拖尾、敌人受击"先脆后晃"）

按策划 2026-11-28《判定跟着画面弯、粒子改真拖尾、敌人受击做成"先脆后晃"》做的。

- **判定 = 画面上那把刀**：判定沿弯刃的中线分 5 段取样（每段一根胶囊），和着色器用同一套刃形公式（`_blade_point`）。
  画面上的刃方向和长度不再用弹簧追判定，而是和判定完全一致（只有收刀时长度还有弹性）。
  中线比刃口靠后半个刃宽，所以有误差也偏"晚"
- **拖尾**：液滴和丝缕删了，换成"刀路过、粒子留在原地"：从刃后面那条薄边上生成，初速度上限 0.3 米/秒，0.35 秒淡掉。
  颗粒 + 顺着刀路躺下的细丝两种，大小寿命随机。参数在"攻击动作（全细胞）"组的 `trail_*`
- **敌人受击"先脆后晃"**：新的通用组件 `scripts/fx/hit_wobble.gd`（HitWobble 资源，Enemy 的 `hit_wobble`）：
  1 定格期间完全不动 → 2 接触点凹进去 → 3 整条被推开、离接触点越远越跟不上（杆菌弯腰，圆的会压成碗状）→ 4 回弹约 2 次后停。
  只往膜着色器写参数，不关心是哪种敌人，以后的敌人直接用
  - 膜的流动改用脚本累加的游戏时间（`anim_time`），不再用着色器自带的 TIME——TIME 不受定格影响，定格时膜还在动就不"定"了
  - 敌人的胶囊网格加了环数（沿长度 24 环），不然弯不出弧线
  - 自检：`tests/hit_wobble_smoke.gd`（8 项：定格中形变严格为 0、定格后才开始、回弹不超过 3 次、接触点在敌人身边）；
    `tests/hit_wobble_strip.gd` 出受击逐帧剪影 → `docs/img/hit_wobble_2026-11-28.png`

## 上一批改动（2026-11-28 第六批：刃末端不尖、身体为刃付出体积、边缘丝缕）

按策划 2026-11-28 两条（"是刀不是剑 + 一体感从本体找回来"和它的更正"末端不要尖，两侧都薄"）做的。

- **刃末端没有尖点**：最后 30% 沿平滑曲线收窄到刃宽的 15% 为止（收到头两边是平行的，不形成尖角），
  剩下的一截从收窄段的 35% 处开始变透明、化掉。两侧都薄（对称的扁截面，越往末端越薄），没有刀背
- **单向弯**：顺着挥击的弧往后弯 0.25 弧度（固定形状，不是晃出来的）
- **体积守恒**：刃伸出时身体整体缩小 18%（半径）、刃根周围再凹进去 25%，核也一起缩；收回时按刃的长度鼓回来。
  刃伸出时身体往前鼓的量调小了（轻 0.4→0.15，重 0.55→0.2），否则和"缩小"互相抵消
- **边缘丝缕**：挥动时从刃上甩出细长的丝（长短、粗细、寿命都随机），留在原地，所以拖在挥击后面；液滴保留
- 参数都在"攻击动作（全细胞）"组：`blade_end_width` / `blade_fade_start` / `blade_curve` / `body_shrink` / `body_dent` / `wisp_*`
- 剪影：`docs/img/silhouette_2026-11-28_organic.png`

## 上一批改动（2026-11-28 第五批：刃改成刀的形状、删掉软/硬 A/B、挥扫加速度曲线）

按策划 2026-11-28《刃形规格重写》做的（策划认错：上一轮"越往尖端越软"造出了鞭子）。

- **刃的形状照冷兵器**：不再从球面"拉长"（那样宽度沿长度匀速变小 = 圆锥），而是按刀的轮廓直接摆顶点——
  宽 0.7 米，到全长 78% 都几乎等宽（只收窄到 90%），最后 22% 收尖；截面是扁的透镜形（厚 = 宽 × 0.15），宽面躺在挥击平面里；
  根部只有全长 15% 的一小段从身体过渡；整体直的，只带 0.1 弧度单向的弯。参数在"攻击动作（全细胞）"组
- **刀身是硬的**：分段弹簧、"软/硬"A/B（F2）全部删除。刃方向的弹簧调得很紧（几乎不冲过头），过冲只留给身体
- **"唰"来自速度曲线**：挥扫角度 = 进度²（`swing_ease_power`）：起手慢、越挥越快、到头硬停。判定和画面都按这条曲线走
  （判定逐段检测的步数按最快那段算，不会扫过头漏掉目标）
- 剪影图已被第六批替换
- F2 / 十字键上 空出来了，留给以后的 A/B

## 上一批改动（2026-11-28 第三批：锁定接管镜头、攻击改为全细胞动作）

按策划 2026-11-27《锁定改为接管镜头 + 攻击动作全细胞大改》做的。

- **锁定 = 镜头完整接管**：镜头站到"主角 → 目标"连线后方，目标保持在画面中心区域；目标在上方镜头抬头、在下方低头；
  拉远 2 米、视野加宽 10°（`FollowCamera` 的"锁定时"组）。锁定时右摇杆不起作用；解锁 = 再按一次锁定键。
  **切换目标 = 十字键 ← →（键盘 Z / C）**，按画面上的左右找相邻的那只，那一侧没有就不动。
  上一版的"右摇杆拨一下切换""镜头只轻微偏向"已删除
- **攻击 = 全细胞动作，没有刃模型了**：原来的伪足圆柱/圆锥和"鼓包"球都删了。刃是身体的膜被拉出去的那一段（着色器顶点形变）：
  根部就是身体（膜上 72° 以内都参与），越往外越薄、沿挥动轴压扁，尾部被甩在后面而弯
  - **蓄**：前摇时整团质量往出手方向的反面聚，背面鼓、核往后挪（重击明显，轻击短）
  - **发**：画面上的刃用弹簧追判定，所以尾部有弯、有"甩"；整团质量跟着往前冲；膜纹顺挥击方向拉成条纹并流动
  - **过冲**：判定停了，刃的方向弹簧还带着速度，冲过头再被拽回
  - **沉**：刃收回时那股冲劲交给整团质量，身体再晃一会儿；胞质流动慢慢散回乱流
  - 刃尖甩出小液滴（大小、寿命、方向都随机）
  - 判定没动：仍按挥扫的角度和长度算。⚠ 画面上的刃比判定晚一点点（弹簧追的），打中的那一刻刃尖可能还差十几度没到
  - 全部参数在 Player 的"攻击动作（全细胞）"组；待机时的朝向小方块出手时隐藏
- **逐帧剪影自检**：`tests/silhouette_strip.gd` + `tests/silhouette_strip.py`，轻击/重击 × 俯视/身后，各 16 帧纯色剪影。
  当前结果存在 `docs/img/silhouette_2026-11-28.png`
- 测试：lock_smoke 改成接管版（19 项），其余全过

## 上一批改动（2026-11-28 第二批：一下一下、伪足长出来、锁定、描边）

按策划 2026-11-27《攻击要有边界、伪足要浑然一体、加锁定系统》四条做的。

- **轻击有了边界**：每一下 = 前摇 0.07 秒（刃在膜上成型，小鼓包）→ 挥 0.1 秒 → 后摇 0.22 秒（前 30% 刃停住，后 70% 流回身体）。
  **挥扫中、后摇前段按的直接丢弃，不排队**；只有后摇最后 0.08 秒按的才会缓冲。狂按也是一下一下：
  测试里连按三下首尾间隔 0.9 秒（以前约 0.4 秒）。后摇结束后 0.3 秒内再按 = 连段下一下（第 2、3 下前摇缩到 60%），
  过了就从第一下重来。所有时长都是 Player 的 `@export`（攻击 · 连续轻击）
- **伪足是从身体里长出来的**：伪足网格改成锥形，根部宽（身体半径的 75%），往外收细到刃口；
  出手时整个细胞朝出手方向抻长、背面凹进去，收回时弹簧回弹（`伪足与本体形变` 组，着色器顶点形变）。
  重击聚合时本体也跟着鼓
- **锁定**：R3 / Q / 鼠标中键开关。锁上先取准星选中的，没有就在屏幕 45% 半径、18 米内找离准星最近的。
  - 锁定时**攻击和身体朝向全听锁定目标**（准星索敌、按住升降的方向攻击都不参与）
  - **快速拨一下右摇杆**（0.25 秒内推过 70% 再松回）= 按拨的方向切换目标，此时镜头不转；推住不放 = 正常转镜头张望，不切换
  - **镜头不焊死**：只以 0.3 的强度慢慢偏向目标（`FollowCamera` 的"锁定时"组）；推右摇杆时让开，松手 1 秒后再慢慢转回
  - 目标死了 / 超过 25 米自动解锁
  - 显示：目标身上套一个粉色锁定环（正对镜头、不被遮挡），准星同色；被锁的敌人描边换成粉色、最粗最亮
- **描边**：改成按屏幕像素定宽（约 2 像素），掠射角下不再整片发亮。分三档：普通敌人细而暗、被准星选中中等（黄）、被锁定最醒目（粉）
- 试玩记录新增 `lock` 事件（on/off/switch）；sample 记录当时是否锁着；hurt 记录挨打时是否锁着。`analyze_playtest.py` 输出锁定使用率、切换次数、锁定时的受击来源
- 测试：新增 `tests/lock_smoke.gd`（14 项）；combat_smoke 改成新节奏（挥扫中狂按不叠、狂按出三下且有间隔、扳机）；全部通过

## 上一批改动（2026-11-28：扳机 bug、细胞材质）

- **修了"一按打三下"**：手柄 RT 是模拟轴，拉动过程中每个超过死区的位置都让 `is_action_pressed` 为真，
  实测拉一次 = 5 次"按下"，于是自动接出三段连击。现在只认"从没按到按下"的那一刻（玩家和试玩记录器都改了）。
  轻击现在就是**一次输入一次挥**，连段要自己一下一下按出来，左右交替保留。
  ⚠ 之前的试玩记录里，用手柄时的轻击次数和 input 事件都偏多
- **细胞材质**（`shaders/cell_membrane.gdshader` + `scripts/fx/cell_look.gd`，没有贴图、没有建模）：
  - 半透明膜 + 里面一个实核（核用代码生成，大小、偏移是观感参数）
